# Jordi Roura · Portfolio 2026

Portfolio professional de Jordi Roura, desenvolupat amb una stack moderna i exportació estàtica per GitHub Pages.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- GitHub Actions / GitHub Pages

## Desenvolupament local

```bash
npm install
npm run dev
```

## Build

```bash
npm run typecheck
npm run build
```

El projecte està configurat amb `output: "export"` per generar una versió estàtica compatible amb GitHub Pages.
